# AGENTS.md — Archived Agent Notes

Archived Agent Notes under the class directories are frozen historical snapshots, not current authority. Never edit, reformat, repair, delete, or move a sealed file; use an active Agent Note or current documentation for new decisions and facts.

The archival change may only relocate an implemented Agent Note, insert an `Archived: YYYY-MM-DD` line below its `Status: implemented` line, and repair or delete inbound links. Do not inspect, verify, or repair links out of archived notes.

Run `python3 scripts/verify_agent_notes.py` after an archival change. The verifier rejects unknown class folders and invalid archive metadata.
